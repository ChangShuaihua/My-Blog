**LangChain 是**现在最流行的 AI 应用框架，它提供 Python 和 JavaScript 两个版本。为了快速上手，我们会用 JS 版本开始学习，两者思想基本一致，你熟悉其中一个版本，切换到另一个版本通常**只需要半天**就能适应。

**LangChain.js 是什么**
--------------------

LangChain.js 可以理解为一个“帮你更方便地做 AI 应用的工具箱”。它的核心作用，不是自己训练大模型，而是把大模型、提示词、外部数据、API、数据库和业务流程串起来，让开发者更快做出能聊天、能检索、能自动执行任务的应用。

如果把大模型比作一个很聪明但有点“单线程”的脑袋，那么 LangChain.js 就像给它加上了手脚、记忆和工具箱。它让模型不只是回答问题，还能查资料、调用接口、按步骤做事。LLM 的 API 只是提供了一个非常基础的调用方式，当我们要构建一个复杂的 Chat Bot 时，就需要考虑如何保存聊天的上下文、如何进行网络搜索、如何加载 pdf 等等工程问题，这些都是应用框架可以帮助我们解决的

**它能做什么**
---------

LangChain.js 常见用途有几类。第一类是做聊天机器人，比如客服助手、知识问答机器人、个人助理。

第二类是做“基于资料回答问题”的应用，比如把公司文档、产品手册、FAQ 接入系统，用户提问时先检索资料，再让模型组织答案。

第三类是做自动化流程，比如“先提取用户信息，再调用接口，再生成回复”，把多个步骤串成一条链。

**为什么要用它**
----------

普通开发者直接调大模型接口也能做应用，但当流程开始变复杂时，代码很容易变乱。LangChain.js 提供了一套现成的组件和抽象，让你不用每次都从零写提示词管理、数据加载、文本切分、检索和链式调用。

它最大的价值在于“组合能力”。你可以把不同模块拼起来，形成适合自己业务的 AI 工作流，而不是只停留在“问一句，答一句”的简单聊天。

**里面有哪些常见概念**
-------------

LangChain.js 里最常见的几个概念不难理解。Prompt 是你喂给模型的提示词模板；Chain 是把多个步骤连起来的流程；Agent 则更灵活，会根据情况自己决定要不要调用工具。

如果你要做知识库问答，通常还会碰到 Document、Text Splitter、Vector Store 这些词。Document 是加载后的文本，Text Splitter 负责把长文切成小块，Vector Store 则用来保存和检索这些内容。

**一个简单例子**
----------

比如你想做一个“旅游助手”。用户输入“帮我规划东京三日游”，LangChain.js 可以先让模型理解需求，再调用天气或地图 API，再根据结果生成行程建议。

再比如做企业知识库问答。用户问“报销流程是什么”，系统先从文档里找相关段落，再把这些段落交给模型整理成自然语言答案，这样通常比直接让模型凭空回答更稳。

**适合谁用**
--------

LangChain.js 很适合前端开发者、全栈开发者和想快速做 AI 产品的人。因为它基于 JavaScript/TypeScript 生态，和 Web 开发、Node.js、前端项目结合比较自然。

如果你只是想“调用模型生成文本”，它可能有点重。可是一旦你需要接文档、接工具、接业务流程，它就会变得非常有用。

**新手怎么入门**
----------

入门时，最好的方式不是一上来就做复杂系统，而是先做三个小练习：一个提示词模板、一个简单链、一个带检索的问答 demo。

你可以先理解这条最基本的思路：输入问题，经过提示词处理，再交给模型生成答案。等你把这条线跑通，再逐步加上文档、工具和自动化流程。

**总结理解**
--------

一句话说，LangChain.js 是“让大模型更像一个能干活的应用组件”的开发框架。它的重点不在模型本身，而在于把模型和真实业务连接起来。

如果你把 AI 应用看成一辆车，大模型是发动机，LangChain.js 更像方向盘、变速箱和仪表盘。它不负责提供全部动力，但能让这辆车更容易开、也更容易开到想去的地方。
